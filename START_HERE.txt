🚀 TO GET STARTED (3 STEPS):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALL DEPENDENCIES

   Terminal 1:
   $ cd /workspace/server
   $ npm install

   Terminal 2:
   $ cd /workspace/client
   $ npm install

2. SEED THE DATABASE

   Terminal 1:
   $ cd /workspace/server
   $ node seedData.js

   (This adds sample testimonials and universities)

3. START BOTH SERVERS

   Terminal 1 (Backend):
   $ cd /workspace/server
   $ npm start

   Terminal 2 (Frontend):
   $ cd /workspace/client
   $ npm start

   Your browser will open to: http://localhost:3000

⚠️  MONGODB SETUP:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A: MongoDB Atlas (Cloud - Recommended for quick start)
   1. Visit: https://www.mongodb.com/cloud/atlas
   2. Sign up (free)
   3. Create cluster (free tier)
   4. Get connection string
   5. Update server/.env with your connection string

Option B: Local MongoDB
   - Make sure MongoDB is installed and running
   - Default config in server/.env works out of the box
